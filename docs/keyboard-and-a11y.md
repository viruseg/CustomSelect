# Клавиатура и доступность

Библиотека полностью управляема с клавиатуры и следует WAI-ARIA паттернам listbox.

## Клавиатура на основном модуле

Когда фокус на триггере (`.csel-root`):

| Клавиша | Действие |
|---|---|
| `Enter` | Открыть список |
| `Space` | Открыть список |
| `ArrowDown` | Открыть список, активировать **первую** доступную опцию |
| `ArrowUp` | Открыть список, активировать **последнюю** доступную опцию |
| `Backspace` | Удалить последний выбранный тег (только multiple; не работает в поле поиска) |
| `Escape` | Закрыть список, если открыт |

## Клавиатура в списке

| Клавиша | Одноколоночный режим | Многоколоночный режим (`columns > 1`) |
|---|---|---|
| `ArrowDown` / `ArrowUp` | Предыдущая/следующая опция | На строку вниз/вверх (внутри колонки) |
| `ArrowLeft` / `ArrowRight` | — (игнорируются) | Между соседними колонками |
| `Home` / `End` | Первая / последняя доступная опция | Те же |
| `Enter` / `Space` | Выбрать/снять активную опцию | Те же |
| `Escape` | Закрыть список | Закрыть список |

Правила навигации:

- **Без wrap-around**: на границе списка навигация останавливается.
- **Disabled-опции пропускаются** в направлении движения.
- Заголовки групп не являются позициями навигации и никогда не получают активность.
- Ввод в поле поиска работает в любой момент: фокус остаётся на якоре, а активная опция трекается атрибутом — печать не прерывается перемещением по списку.

## Начальный фокус

| Как открыли | `searchable=true` | `searchable=false` |
|---|---|---|
| Клик / toggle-кнопка / Enter / Space | Фокус в поле поиска | Активна первая опция |
| `ArrowDown` на триггере | Активна первая опция | Активна первая опция |
| `ArrowUp` на триггере | Активна последняя опция | Активна последняя опция |

При закрытии любым способом фокус возвращается на toggle-кнопку основного модуля.

## ARIA

Основной модуль:

```html
<div class="csel-root" role="group" tabindex="0" aria-disabled="false">
    <button class="csel-toggle"
            aria-haspopup="listbox"
            aria-expanded="false"
            aria-controls="csel-N-popover">
```

Popover:

```html
<div id="csel-N-popover" popover="manual" class="csel-popover">
    <input type="search" class="csel-search-input">   <!-- с доступным label -->
    <div role="listbox" aria-multiselectable="true">  <!-- multiselectable — только в multiple -->
        <div role="option"
             id="csel-N-opt-0"
             aria-selected="true"
             aria-disabled="false">
```

Ключевые решения:

- Триггер — **не** combobox: он не является текстовым полем. Editable textbox (поиск) — отдельный контрол внутри popover.
- Активная опция трекается через **`aria-activedescendant`** на якорном элементе (поле поиска или сам listbox), а не через реальный фокус на опциях — это стандартный паттерн для select'ов с поиском.
- Чекбоксы в multiple mode — чисто визуальные (`aria-hidden`), клик по всей строке переключает выбор.
- Каждый экземпляр получает уникальные DOM-id (`csel-1-popover`, `csel-1-opt-0`, …) — несколько компонентов на странице не конфликтуют.

## Доступные имена

Доступное имя опции строится по цепочке:

1. `ariaLabel` элемента данных;
2. иначе `searchKeywords.join(', ')`;
3. иначе `String(id)`.

Поэтому image-only элементы (у которых нет текста) всегда озвучиваются скринридером:

```js
{ id: 7, type: 'image', content: '/img/red.png', searchKeywords: ['красный'] }
// → доступное имя «красный»
```

Атрибут `alt` у картинок намеренно отсутствует — изображение декоративно, имя несёт сама опция.

## Видимость фокуса и reduced motion

- Фокусные состояния оформлены (`border-color: var(--csel-border-focus)` + outline на listbox).
- При системной настройке `prefers-reduced-motion: reduce` анимация появления popover отключается автоматически, независимо от конфига `animations`.
